# MLOps Practical Lab

This material is based on the MLOps practical repository developed for
the KAUST Abha Summer School.

## Learning Objectives

After completing this material, you should be able to:

-   Understand the machine learning lifecycle
-   Build reproducible machine learning pipelines
-   Track experiments and model versions
-   Containerize machine learning applications using Docker
-   Understand Kubernetes deployment basics
-   Monitor deployed models
-   Retrain models when data distributions change
-   Apply MLOps best practices in real-world projects
